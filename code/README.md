# 长征官方文献试点

在本目录运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，浏览器打开 http://127.0.0.1:8765 。仅监听本机；无显卡要求。Python 3.10+，网页功能无需额外依赖。

## 工作流程

1. 在页面的官方站点入口检索，找到史料正文；填入原文网址。也可使用已核实的两个种子页面。
2. 提交采集后点击“任务状态”查看进度。采集遵守 robots.txt，单个文件上限 20 MB，图片间隔一秒。未授权域名、跨域重定向被拒绝。扩展白名单前必须确认机构性质；外部图片域名须另行核实。
3. 文献库查看正文、出处、图片记录，确认纳入或排除。网站官方身份不等于文献已通过筛选。报道通知规则只是初筛，最终人工判断。
4. 事件界面核对证据，修改事件名称、填写说明，确认或排除。
5. 导出 JSON、CSV、Markdown。所有导出保留状态，未确认内容不应作为已核实史实。被排除文献的事件不进入导出；被排除事件仍保留，便于审计。

数据默认写入 `../gpt/1022/长征文献试点/`：SQLite 数据库、raw 原件、exports 导出。备份时停止程序并复制整个数据目录。数据库包含文献哈希，可识别内容相同的原件；当前不跨网址合并，以免丢失来源。相同网址不会重复采集，避免覆盖人工核对。

## 试点边界

- 已支持官方来源自动链接遍历与 sitemap.xml 发现，见下方说明；也保留人工网址采集。
- 覆盖部队词典含中央红军、红一/二/四方面军、红二十五军、红二/六军团；它是提取能力，不代表现有数据库已覆盖所有部队。
- 年月日用原文保存，只提取明确出现 1934—1936 年的句段。不会根据网页发布日期或上文猜测年份；月日、省略年份、中文数字日期可能漏提。多日期、日期区间需人工核对，未进行历史地名现代化、事件跨文献归并或战役因果推断。
- 人物、地点使用可编辑词典；职务、上下级关系、伤亡、战斗过程与结果暂保留在原文证据内，没有独立自动抽取字段。事件名称为原句截取，供人工修订。
- 网页正文采用常见容器与全文回退；复杂布局可能包含导航，必须核对。图片原件与说明会记录下载结果，未提取图片版权许可；使用前查阅原站说明。
- PDF 安装 `requirements-optional.txt` 中的 pymupdf 后解析；扫描 PDF 需要后续 OCR 扩展。独立图片需 Pillow、pytesseract，以及本机安装 Tesseract 和 chi_sim 中文语言包；无组件时报告明确错误并保留原件，不伪造识别结果。OCR 为 CPU 模式。
- 没有内置大模型，不会自动编写完整历史叙事。尚未提供全文字段编辑、修订历史、图片在线预览或扫描 PDF 逐页 OCR。
- 单机个人使用；失败任务保留错误可重新提交。后台采集线程在关闭程序时终止，重新启动后需要重新提交未完成任务。

## 可核实试点出处

- 中共中央党史和文献研究院：《长征·光辉历程》 https://www.dswxyjy.org.cn/n1/2016/0930/c396983-28753123.html
- 中共湖北省委党史研究室：《先锋之师——红二十五军长征》 https://www.hbdsw.org.cn/tbgz/zggcd/fjlc/202110/t4544087.shtml

这两个地址是检索确认的候选史料。开发验证已实际采集第一份《长征·光辉历程》，保存原件及两条待核对事件。网页图片可能包含站点标识，图片记录需要人工筛选。原件和提取结果以实际采集、人工核对为准。

运行验证：`python -m unittest discover -s tests -v`。

## 自动检索

重启程序后，页面顶部点击“启动 / 断点继续”。默认每轮最多200页、深度4；可增加上限（最多100000页、深度30）。按长征与各部队关键词筛选候选文献，报道通知候选不自动纳入。种子、站点首页和 sitemap.xml 自动入队，HTML链接包含分页链接，sitemap索引中的子图亦自动入队。相同URL去重；全队列、父页面、深度、命中词、错误和尝试次数写入 SQLite。

暂停后当前页面完成再停；关闭程序后再次启动可恢复未完成队列。失败页通过“重试失败并继续”最多尝试三次。增加深度可继续访问之前超出深度的队列项。已检索页面不自动重新扫描，站点更新复查暂未实现。

命令行：`python crawler.py 200`。不要同时运行命令行采集与网页采集，单工作线程保护仅在同一进程内生效。自动检索进度在网页手动刷新，不会因关闭页面停止。

覆盖范围是配置白名单的公开链接图，不等于全国全部官方文献：未链接网页、动态检索接口、需要登录资料、验证码、robots禁止路径无法保证覆盖。当前仍只有两个确认的官方机构；扩展来源需在 config.json 添加机构、域名与种子。既有媒体排除规则维持。网页中仅因导航文字命中关键词的候选仍可能进入文献库，需人工确认。公开图片保留下载结果与错误，不自动判定图片史料价值。
