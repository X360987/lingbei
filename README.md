# 星火档案 · 零杯网页设计项目

长征主题展示网站，以及用于整理官方文献的本地 Python 采集工具。展示网站与采集工具是两个独立入口；同步代码不会自动同步文献数据库，也不会自动部署网站。

## 目录与入口

| 路径 | 用途 |
| --- | --- |
| `index.html` | 展示网站首页 |
| `archive.html` | 历史档案与知识图谱页面，首页链接到此处 |
| `assets/` | 网站图片等静态素材 |
| `code/` | 文献采集工具、配置、测试及详细使用说明 |
| `code/index.html` | 采集工具界面，由 Python 服务提供 |
| `gpt/1022/长征文献试点/` | 本地采集数据库、原件、导出及研究整理记录 |
| `学习日志/`、根目录 Word/PPT | 学习记录、设计方案与比赛参考资料 |

## 预览展示网站

安装 Python 3.10 或以上版本，在项目根目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 <http://127.0.0.1:8000/>，从首页进入档案页面。按 `Ctrl+C` 停止服务。

## 启动文献采集工具

在项目根目录运行：

```powershell
python code/app.py
```

浏览器访问 <http://127.0.0.1:8765/>。基础网页功能只需要 Python 标准库；PDF 与 OCR 功能的可选依赖、系统组件和采集流程见 [code/README.md](code/README.md)。

也可使用现有 Windows 启动脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\code\start.ps1
```

数据路径由 `code/config.json` 中的 `data_dir` 指定，相对于 `code/` 解析。默认写入 `gpt/1022/长征文献试点/`。首次使用会创建数据库；新克隆的仓库不包含现有采集数据库和原件，需要自行采集或另行取得数据快照。此工具目前用于单机运行。

## 验证修改

采集工具的单元测试：

```powershell
cd code
python -m unittest discover -s tests -v
```

网页修改后，启动静态服务检查首页、档案页、页面间跳转和图片加载，并在窄屏尺寸下检查布局。

## GitHub 协作约定

建议先创建私有仓库，以项目根目录作为仓库根目录。首次提交前检查 `git status` 和暂存区内容，确认提交范围。

- 源码、必要素材、测试、共享配置和说明文档纳入版本控制。
- `.gitignore` 排除 Python 缓存、本地虚拟环境、环境密钥文件、SQLite 数据库及其临时文件、采集原件、生成的导出文件和根目录 `archive.zip`。忽略规则不会删除本地文件，也不会自动取消对已跟踪文件的跟踪。
- `gpt/` 下的采集记录、节点切分等研究资料仍可提交；不要把整个目录都当作临时文件。
- 开始工作前更新主分支，每项修改使用独立分支，通过 Pull Request 审阅后合并。避免多人同时修改同一 HTML 的同一区域。
- Word/PPT 可以存档，但难以合并并行修改。指定一人维护同一文档，或将需要经常协作的文字说明整理成 Markdown。
- 新增配置不要写入密码、访问令牌或个人机器绝对路径；环境配置示例可放在 `.env.example`，但当前程序不会自动读取该文件。

## 数据交接与备份

SQLite 数据库不通过 Git 进行多人合并。交接已有采集结果时，停止采集工具，备份整个 `gpt/1022/长征文献试点/` 目录，通过单独的数据快照交接；接收方替换前也应停止程序并备份自己的数据。约定一位维护者汇总结果，避免相互覆盖。

导出文件默认不提交。如需把经过核实的数据作为网站内容发布，请将选定的数据复制到专门的版本化目录，并记录来源、核实状态和更新日期。

## 资料与公开发布

本仓库含比赛资料、学习日志与第三方史料素材。公开仓库或发布网站前，应检查文档中的个人信息以及素材的使用许可。官方来源不等于可任意转载；史料仍需人工核对。当前未为整个项目声明统一开源许可。
